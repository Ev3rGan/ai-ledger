# Security Policy

## Supported versions

Security fixes are applied to the `main` branch and the currently deployed release. Older commits and abandoned branches are not supported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's private [Report a vulnerability](https://github.com/Ev3rGan/ai-ledger/security/advisories/new) form. Include the affected component, reproduction steps, impact, and any suggested mitigation. Please avoid including real credentials or sensitive production data.

The maintainers will review the report, coordinate a fix when confirmed, and disclose it after affected users have a reasonable opportunity to update. Response times are best effort; no fixed service-level agreement is currently offered.
