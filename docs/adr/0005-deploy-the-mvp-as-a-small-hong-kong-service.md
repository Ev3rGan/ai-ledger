# Deploy the MVP as a small Hong Kong service

The MVP targets visitors in mainland China but will initially run as a single-region Hong Kong personal service. To remain within USD 15-30 per month, one 4 GB virtual machine will self-host the Web process, scheduled worker, and PostgreSQL/pgvector, while daily logical backups are copied off-machine; Tencent Cloud Lighthouse, AWS Lightsail, and Alibaba Cloud remain benchmark candidates until mainland-network, outbound-access, and restoration tests select one. The project is a real portfolio and personal-production tool, not a multi-tenant SaaS, so it accepts brief downtime and excludes billing and high-availability machinery; all usage-metered external APIs together, including model and managed-extraction calls, are separately capped at USD 100 per month. Mainland deployment remains a later decision that requires filing and compliance review rather than an implicit migration.
